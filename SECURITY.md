# Security Policy

## Supported Versions

We actively support and patch the following versions of the Food Freshness Image Prediction System:

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of our application and data seriously. If you find a security vulnerability, please do not open a public issue. Instead, report it directly to the maintainers:

* Email: **<jewimaluwi2019@gmail.com>**

Please include as much detail as possible in your report, including:

* The nature of the vulnerability.
* Steps or a proof-of-concept to reproduce the issue.
* Potential impact.

We will acknowledge receipt of your vulnerability report within 48 hours and work to provide a fix or mitigation plan as quickly as possible.
